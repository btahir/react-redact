# Local Vite demo

From the repository root, run `pnpm install`, `pnpm build`, and `pnpm --filter react-redact-vite dev`. Open http://localhost:4314. `pnpm --filter react-redact-vite build` produces a static application you can host yourself.

The app generates every record using demo-only entity IDs. It has no API keys, database, or network data fetch. The optional Studio writes only authored policy drafts to this origin's localStorage. Clear saved drafts from the editor when finished.
